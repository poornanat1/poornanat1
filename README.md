# Poorna Natarajan

Building LLM systems focused on retrieval quality, safety, and measurable prompt optimization.

## Featured Work

### CareNav
Health-benefits navigator with citation-grounded answers and safe escalation.

- Typed Python orchestration: safety -> intent -> tools -> grounded response -> verify -> respond/escalate
- Hybrid retrieval with Postgres (`pgvector` + full-text)
- Cost-aware model routing, PII tokenization, and CI eval gates for safety regressions

Links: [Repo](https://github.com/poornanat1/carenav) | [Live Demo](https://carenav-frontend-production.up.railway.app/)

### dspynet-gepa-bench
Benchmark of GEPA reflective prompt evolution on SEC S-1 extraction (RealKIE), across Anthropic and Mistral model pairs.

- Best observed gain: Haiku 4.5 + Sonnet 4.6 from 0.386 to 0.622 (+23.6 pp)
- Stronger reflectors consistently help weaker task models

Link: [Repo](https://github.com/poornanat1/dspynet-gepa-bench)

### DSpyNet
Contributor to the C#/.NET port of Stanford DSPy.

- Added GEPA optimizer in [PR #1](https://github.com/al322se/DSpyNet/pull/1)
- Improved parity with upstream DSPy in [PR #2](https://github.com/al322se/DSpyNet/pull/2)

Links: [Repo](https://github.com/al322se/DSpyNet) | [NuGet](https://www.nuget.org/packages/DSpyNet)
